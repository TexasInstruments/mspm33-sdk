MSPM0 诊断库

MSPM0 诊断库是功能安全软件的集合，可帮助客户满足其功能安全诊断需求。

诊断库具有以下特性：

  • 减少 IEC60730 B 类应用所需的开发工作量
  • 支持 MSPM0 系列
  • 包括诊断库安全手册
  • 通过未来发展支持 IEC-61508 和 ISO-26262
