ec.h File Reference

Detailed Description

Elliptic curve implementations for ECDSA, ECDH.

This cipher module implements elliptic curve cryptography for enabling ECDSA key generation, signing, and verification and ECDH key agreement based on cryptographic elliptic curves defined over a prime field Fp.
