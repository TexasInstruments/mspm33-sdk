curve25519.h File Reference

Detailed Description

Edwards curve (Ed25519) digital signature verification.

This module implements Ed25519 signature verification as defined in RFC 8032. Ed25519 is a signature scheme using a twisted Edwards curve that is birationally equivalent to curve25519.

uint8_t  shared_secret[X25519_KEY_LENGTH] 
)

Performs an X25519 key exchange operation.

This function computes a shared secret using the X25519 Diffie-Hellman key exchange protocol. It takes the caller's private key and the peer's public key as input and produces a shared secret that can be derived by both parties.

Parameters
[in]skThe caller's 32-byte private key.
[in]peer_pkThe peer's 32-byte public key.
[out]shared_secretBuffer to hold the 32-byte computed shared secret.
Returns
The resulting status of the operation, one of crypto_x25519_stat_t.
Return values
CRYPTO_X25519_STAT_SUCCESSif the key exchange was successful.
CRYPTO_X25519_STAT_ERRORif an error occurred during key exchange, such as the peer's public key being a point of small order.
CRYPTO_X25519_STAT_INVALID_PARAMif any of the input parameters are invalid.
Note
The shared secret should not be used directly as an encryption key. It should be passed through a key derivation function (KDF).

Verify an Ed25519 digital signature for a message using an Ed25519 public key.

Parameters
[in]msgPointer to the message verify.
[in]msg_lenLength of the message in bytes.
[in]sigPointer to the 64-byte Ed25519 signature. The first 32 bytes contain the R value, the second 32 bytes contain the S value.
[in]pkPointer to the 32-byte Ed25519 public key.
Returns
The resulting status of the operation, one of crypto_ed25519_stat_t.
Return values
CRYPTO_ED25519_STAT_VALID_SIGNATUREif the signature was valid for the message and public key.
CRYPTO_ED25519_STAT_INVALID_SIGNATUREif the signature was not valid for the message and public key.
CRYPTO_ED25519_STAT_INVALID_PARAMif any of the input parameters are invalid.
CRYPTO_ED25519_STAT_ERRORif an error occurred during verification.
