ml-kem.h File Reference

Detailed Description

Module lattice key encapsulation mechanism (ML-KEM)

This module implements the FIPS 203 standard for a post-quantum resistant key encapsulation mechanism (Crystals: Kyber) , providing a KEM implementation with the following properties:

  • IND-CPA secure (indistinguishability under a chosen plaintext attack)
  • IND-CCA secure (indistinguishability under a chosen ciphertext attack)
