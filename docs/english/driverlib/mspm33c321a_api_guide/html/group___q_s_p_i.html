Detailed Description

Overview

The Serial Peripheral Interface Driver Library allows full configuration of the MSPM33 QSPI module. The serial peripheral interface (QSPI) module provides a standardized serial interface to transfer data between MSPM33 devices and other external devices with QSPI interface.
