32 /*!****************************************************************************
33  * @file rsa.h
34  * @brief Compact implementations of RSA signature verification
35  *
36  * This cipher module implements signature verification for RSA type
37  * digital signatures. Currently, the following parameters are supported:
38  *
39  * Public exponents: 65537 (performance optimal and most common use case)
40  * Modulus size: 2048-bit (256-byte)
41  * Padding schemes: EMSA-PKCS1-v1_5, EMSA-PSS-VERIFY
42  * Hash functions: SHA-256 (for message digests and use inside the MGF)
43  *
44  * There are two ways to use the module:
45  * (1) Slower, but single call: use Crypto_RSA_PKCS1P5_verify() or
46  * Crypto_RSA_PSS_verify() and pass the modulus directly. This is
47  * a 1-step process but uses more CPU cycles because the public key
48  * parameters for verification need to be computed from the modulus.
49  * (2) Faster, but 2 calls: use Crypto_RSA_preparePkFromModulus() first
50  * to prepare a crypto_rsa_fast_verify_pk_t for each public key to
51  * be used. Then, use the Crypto_RSA_PKCS1P5_fastVerify() or the
52  * Crypto_RSA_PSS_fastVerify() function to perform RSA verification
53  * on the public key after the public key parameters are pre-computed
54  * in advance. This is faster at runtime. It is possible to call
55  * Crypto_RSA_preparePkFromModulus() during application development /
56  * key installation, and store the crypto_rsa_fast_verify_pk_t data
57  * into flash. Then, only the fast verify functions need to be used
58  * at run time.
59  *
60  * NOTE: These routines expect the application to compute the message digest
61  * of the message being verified using SHA-256. A pointer to the
62  * SHA-256 message digest is then passed in to the RSA verification
63  * routines for verification.
64  *
65  ******************************************************************************
66  */
