Detailed Description

AES cipher implementation.

This cipher module implements the advanced encryption standard through a common top level API (presented in this interface) which can be mapped to different underlying hardware/software implementations.

Currently the following internal implementations are supported:

  • MSP AESADV HW peripheral accelerator
#include <stdint.h>

Perform an AES cipher block chained (CBC) MAC on a input plaintext buffer. Inputs must be pre-padded and with length that is a multiple of the block size.

NOTE: CBC-MAC can be insecure in certain scenarios, including cases where the message length is variable. CMAC is recommended instead of CBC-MAC as it is a safer option. CBC-MAC is still included here as it is utilized in DRBG random number generation.

[out]outPointer to the output MAC tag buffer which must be 32-bit word aligned.

Perform an AES counter with CBC-MAC (CCM) encryption/generation operation on the input buffer, storing ciphertext of the payload in the output buffer and the generated tag in the tag buffer. It is valid to have only associated data with no payload, or only payload with no associated data, but one of the two must be present. Inputs are not required to be 32-bit word aligned or pre-padded (the function will pad if required during CBC-MAC tag generation).

Parameters
[in]noncePointer to the nonce (always an input)
[in]nonceLenNonce length, in bytes. Must be between 7 and 13.
[in]aadPointer to the optional input additional associated data AAD buffer (always an input). Must be 'aadLen' bytes in length.
[in]aadLenThe length of the additional associated data, in bytes. Set to zero if no AAD (only payload).
[in]inPointer to the payload plaintest input. Must be 'len' bytes in length.
[out]outPointer to the ciphertext output. Must be 'len' bytes in length.
[in]lenThe length of the payload, in bytes. Set to zero of no payload (only AAD).
[out]tagPointer to the tag buffer. Must be 'tagLen' bytes in length.
[in]tagLenTag length, in bytes. Must be one of { 4, 6, 8, 10, 12, 14, or 16 }.
[in]keyThe AES engine key selection (which key to use).
Returns
Status of the operation, one of crypto_aes_stat_t.
Return values
CRYPTO_AES_OKif the operation completed successfully.
CRYPTO_AES_PARAM_ERRif parameters were incorrect.
CRYPTO_AES_ALIGNMENT_ERRif the length is not a block multiple, or pointers to buffers are not 32-bit word aligned.
CRYPTO_AES_HW_ERRif the AES HW was not enabled.
