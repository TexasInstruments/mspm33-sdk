MSPM33 SDK QuickStart Guide for IAR¶

1. Introduction¶

This guide is intended to assist users in the initial setup and demonstration of running their first MSPM33 application with IAR. This guide is not intended to explain the functionality of IAR. Please refer to the IAR documentation or the IAR IDE Guide for MSPM33 MCUs included with the MSPM33 SDK documentation.

2. Prerequisites¶

The user is expected to have downloaded the following:

  • MSPM33 SDK

  • IAR Embedded Workbench for 9.70.2

    • The TI XDS drivers are required when using the MSPM33 Launchpad’s integrated XDS-110 programmer. For more information, please visit the release notes for IAR C-SPY XDS driver.

  • SysConfig 1.26.0.4407

3. Install the MSPM33 SDK¶

  1. Download and install the latest MSPM33 SDK. Note that there are SDK installers for Windows, Linux and MacOS. The steps below are shown in Windows, but a similar approach should be followed in Linux or MacOS.

  2. Execute the installer. Click Next.

  3. Select an Installation Directory and click Next. Note the installation directory which by default is c:\ti which will install the SDK at C:\ti\mspm33_sdk_<version>\. This path will be referred to as <MSPM33_SDK_INSTALL_DIR> in sections below.

  4. Click Next

  5. After installation is complete, click Finish.

4. Add MSPM33 SDK to IAR¶

In IAR, we need to add the latest MSPM33 SDK version. This step only has to be done once, or when the SDK is updated.

  1. In IAR, click on Tools → Configure Custom Argument Variables

  2. Click the Global tab, and then Import

  3. Navigate to your SDK folder into <MSPM33_SDK_INSTALL_DIR>/tools/iar/ and open MSPM33_SDK.custom_argvars.

  4. The SDK variables should now be installed in IAR. Click OK to close the window.

    Note: Make sure the MSPM33 SDK path and SysConfig path matches the location and version needed for this SDK release.
    If you installed an earlier version of the SDK then make sure to update the path to the current version you want to use.
    Similarly, if the SysConfig path installed on Section 5. Install SysConfig for MSPM33 is incorrect or pointing to an older version, then modify it.

5. Install SysConfig for MSPM33¶

The SDK includes a preliminary version of SysConfig metadata which can be used to evaluate the user experience of MSPM33 SDK.

For more general information about using SysConfig with MSPM33, please refer to Using SysConfig with MSPM33 available in the SDK’s Tools Guide.

  1. Download and install the standalone version (1.26.0.4407) of SysConfig from ti.com

  2. In IAR, select Tools → Configure Viewers from the menu.

  3. Click Import

  4. Navigate to your SDK folder into <MSPM33_SDK_INSTALL_DIR>/tools/iar/ and open sysconfig_iar_setup.xml.

  5. The standalone SysConfig will be associated to .syscfg files.
    Click OK to close window.

  6. Double-check that the SYSCONFIG_ROOT Custom Argument Variable is correctly pointing to the SysConfig folder as described in Section 4. Add MSPM33 SDK to IAR.

6. Import and Build an SDK Example in IAR¶

  1. In IAR, select File → Open Workspace from the menu.

  2. Navigate to an IAR folder in SDK example at <MSPM33_SDK_INSTALL_DIR>/examples/ and open the .eww workspace file. For example <MSPM33_SDK_INSTALL_DIR>/examples/nortos/LP_MSPM33C321A/driverlib/gpio_toggle_output/iar/gpio_toggle_output_LP_MSPM33C321A_nortos_iar.template.eww.

  3. Click OK on the message.

  4. Select a folder to install the example.

  5. To build the example, right click in the project and select Make. Note that SysConfig projects will automatically generate files in the “SysConfig Generated Files” folder.

    Note: Some examples include support for SysConfig to allow for an easier device configuration.
    For a complete list of examples supporting SysConfig, check the MSPM33 SDK Examples Guide.
    For more general information about using SysConfig with MSPM33, please refer to Using SysConfig with MSPM33 available in the SDK’s Tools Guide.

  6. Click the Download and Debug button to download the code.
