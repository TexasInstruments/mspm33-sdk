ml-dsa.h File Reference

Detailed Description

Module lattice digital signature algorithm (ML-DSA)

This module implements the FIPS 204 standard for post-quantum resistant digital signatures (Crystals: Dilithium).

#include <stddef.h>

Generate a ML-DSA-44 digital signature for a message using an ML-DSA secret (private) key.

NOTE: This function call requires a significant amount of available stack memory. Refer to the user's guide for the stack requirements of this function.

Parameters
[out]sigPointer for the memory location to store the generated ML-DSA digital signature output.
[out]sigLenPointer to variable to store the length of the signature in bytes.
[in]mPointer to the message corresponding to the digital signature.
[in]mLenLength of the signature in bytes.
[in]ctxPointer to the context string.
[in]ctxLenLength of the context string in bytes.
[in]randPointer to the a random string (for non-det signing, else NULL (0).
[in]randLenLength of the context string in bytes, or a (0) value if deterministic signing is used.
[in]skPointer to the secret (private) signing key.
[in]hashModeSet to CRYPTO_MLDSA_SIG_MODE_PURE for pure ML-DSA, or CRYPTO_MLDSA_SIG_MODE_PREHASH for pre-hash ML-DSA. If using pre-hash, then parameter m shall be the string concatenation of ( OID || PH(M) ) where OID is the DER encoded hash object identifier and PH(M) is the output of the hash function taken over the message before signing.
Returns
The result of the operation, one of crypto_mldsa_stat_t.
Return values
CRYPTO_MLDSA_STAT_OKif the signature was generated correctly.
CRYPTO_MLDSA_STAT_CTX_TOO_LONGif the context was > 255 bytes.
CRYPTO_MLDSA_STAT_RAND_TOO_SMALLif the randomized signing was selected but the randLen was < 32 bytes.
