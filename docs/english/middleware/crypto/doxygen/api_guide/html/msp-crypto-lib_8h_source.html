59 /*!****************************************************************************
60  * @file msp-crypto-lib.h
61  * @brief TI cryptography library for MSP microcontroller products
62  *
63  * This library implements cryptographic modules for use on TI
64  * microcontroller products including the TI MSPM0, MSPM33 family of MCUs.
65  *
66  * Hardware acceleration is utilized where applicable, else software
67  * based implementations are used.
68  *
69  * The following modules are provided by this package:
70  * - Ciphers (inc. AES)
71  * - Hashes (inc. SHA)
72  * - Elliptic curve (EC) functions
73  * - Post quantum (PQC) functions
74  * - Random number generation functions (rand)
75  * - General utilities for string manipulation (utilities)
76  *
77  * This library package is delivered pre-built and is expected to be used
78  * without any re-compilation. Sources are provided for certain modules
79  * to give transparency on the underlying implementations.
80  *
81  ******************************************************************************
82  */
