59 /*!****************************************************************************
60  * @file drbg.h
61  * @brief Lightweight random module deterministic random bit generator
62  * programming interface based on a minimal feature set CTR DRBG.
63  *
64  * This module implements a deterministic random bit generator (DRBG) for use
65  * in generating cryptographically secure pseudorandom numbers based on
66  * entropy seed data for use in cryptographic operations including key
67  * generation, initialization vectors, and more.
68  *
69  * This module targets compatibility with with the DRBG recommedations
70  * in NIST SP 800-90A, with certain features excluded from the implementation
71  * to maintain a compact implementation for embedded use cases.
72  *
73  * Specifically, this module implements the following DRBG configuration:
74  * - Type: CTR-DRBG
75  * - Cipher: AES-256
76  * - Derivation function (DF) used: Yes
77  * - Block size: 128 bits
78  * - Key size: 256 bits
79  * - Seed size: 384 bits
80  * - Security strength level: 256 bits
81  * - No support for context strings or additional data strings
82  * - Maximum number of requests before reseed is limited to 2^32-1 requests
83  * - Maximum number of data per request is limited to 16KiB
84  * - Reseeding is not supported. If a reseed is required, un-init and
85  * re-init the instance with fresh entropy and nonce.
86  *
87  ******************************************************************************
88  */
