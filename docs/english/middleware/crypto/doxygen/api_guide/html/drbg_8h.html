drbg.h File Reference

Detailed Description

Lightweight random module deterministic random bit generator programming interface based on a minimal feature set CTR DRBG.

This module implements a deterministic random bit generator (DRBG) for use in generating cryptographically secure pseudorandom numbers based on entropy seed data for use in cryptographic operations including key generation, initialization vectors, and more.

This module targets compatibility with with the DRBG recommedations in NIST SP 800-90A, with certain features excluded from the implementation to maintain a compact implementation for embedded use cases.

Specifically, this module implements the following DRBG configuration:

  • Type: CTR-DRBG
  • Cipher: AES-256
  • Derivation function (DF) used: Yes
  • Block size: 128 bits
  • Key size: 256 bits
  • Seed size: 384 bits
  • Security strength level: 256 bits
  • No support for context strings or additional data strings
  • Maximum number of requests before reseed is limited to 2^32-1 requests
  • Maximum number of data per request is limited to 16KiB
  • Reseeding is not supported. If a reseed is required, un-init and re-init the instance with fresh entropy and nonce.

#define CRYPTO_DRBG_CTR_RESEED_INTERVAL   (UINT32_MAX)
 The CTR DRBG maximum requests per reseed; this is artificially capped at 2^32 requests for efficiency and practicality, as most embedded applications will not request more than 2^32 values. NIST SP 800-90A allows for up to 2^48 with CTR-DRBG based on AES, so this implementation is a subset of this.
 
#define CRYPTO_DRBG_CTR_MAX_WORDS_PER_REQ   (16384U)
 The CTR DRBG maximum number 32-bit words per request, calculated as: 2^19 bits DIV 8b/1B DIV 4B/1W = 16,384 32-bit words per request.

◆ Crypto_DRBG_initialize()

crypto_drbg_stat_t Crypto_DRBG_initialize ( crypto_drbg_ctx_t *  ctx,
const uint32_t *  entropy,
const uint32_t *  nonce 
)

Initialize a counter DRBG instance. An entropy string of 256 bits and a nonce string of 128 bits must be provided to this routine for initialization. This routine implements NIST SP 800-90A CTR-DRBG with AES-256, DF, and no personalization string.

Parameters
[out]ctxPointer to the context structure for the instance to initialize.
[in]entropyPointer to buffer containing entropy input. Must be 32-bit word aligned and contain 8 words (256 bits) of entropy.
[in]noncePointer to buffer containing nonce input. Must be 32-bit word aligned and contain 4 words (128 bits) of nonce content.
Returns
The status of the operation, one of crypto_drbg_stat_t.
Return values
CRYPTO_DRBG_OKif the DRBG was successfully initialized.
CRYPTO_DRBG_PARAM_ERRif an input parameter/pointer is invalid.
CRYPTO_DRBG_AES_ERRif the AES module encountered an error.
