Detailed Description

DAP Link layer abstracts UART communication using MCU SDK HAL APIs. The link layer is split into separate Tx and Rx sub-layers to enable independent operation in OS task contexts.

Link layer uses DAP_ERROR_* codes from Dap.h for internal error handling. Focuses on hardware-level errors: HW_BUSY, HW_TIMEOUT, BUFFER_OVERFLOW, UNSUPPORTED_MODE.
