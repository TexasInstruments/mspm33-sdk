## Example Summary

This code example demonstrates how to use the ECDSA sign function
over the NIST curve P-384 to generate a signature.

This example focuses on the ECDSA operation, and excludes pre hashing.

## Peripherals & Pin Assignments

| --- | --- | --- |
| DEBUGSS | PA20 | Debug Clock |
| DEBUGSS | PA19 | Debug Data In Out |

Compile, load and run the example.  Set break points at the trap loops at the end of main() to verify correct execution.
