## Example Summary

This code example demonstrates how to use the ML-DSA-44 sign
function to sign a message with a ML-DSA-44 secret key using the pre-hash
signing mode (message hashed before signing) with context string.

This example uses SHA-512 as the pre-hash algorithm.

The NIST CAVP FIPS 204 ML-DSA key generation test case ID #24 is used here
to demonstate the prehash and sign computations.  The routine is expected
to return a success status and the actual (computed) signature is
expected to match the expected (stored) signature.
