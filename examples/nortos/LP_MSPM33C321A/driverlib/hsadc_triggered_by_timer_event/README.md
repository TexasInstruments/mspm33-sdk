## Example Summary

The following example configures HSADC0 and TIMA_0 to trigger a single conversion on zero event of the timer.

For more information about jumper configuration to achieve low-power using the

## Example Usage
Compile, load and run the example.
Provide a valid voltage to A3 between 0 - VCC.
The debugger reaches a breakpoint at which results can be verified by the user.

On powerup, the ADC pin(s) used in this example are by default set to
the correct analog mode. Therefore, calls to
DL_GPIO_initPeripheralAnalogFunction for pinmuxing those pins are not needed.
