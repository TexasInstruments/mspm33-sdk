## Example Summary

The following example configures the WWDT in interval mode with an interval
of 2Hz. A LED is toggled at every interval of 2Hz (500ms).
LFCLK is sourced from the internal low frequency oscillator (LFOSC).
The device remains in STANDBY mode while waiting for an interrupt.

### Low-Power Recommendations
TI recommends to terminate unused pins by setting the corresponding functions to
GPIO and configure the pins to output low or input with internal
pullup/pulldown resistor.

SysConfig allows developers to easily configure unused pins by selecting **Board**→**Configure Unused Pins**.

For more information about jumper configuration to achieve low-power using the
MSPM33 LaunchPad, please visit the [LP-MSPM33C321A User's Guide](https://www.ti.com/lit/pdf/slau962).

## Example Usage
The WWDT is configured in interval timer mode with the following settings:
- Watchdog Source Clock = (LFCLK Freq) / (WWDT Clock Divider) = 32768Hz / 4 = 8.19 kHz
- Watchdog Period = (WWDT Clock Divider) ∗ (WWDT Period Count) / 32768Hz = 4 * 2^12 / 32768Hz = 500.00 ms

Compile, load and run the example. The green LED will toggle every 500ms. The example will wait for interrupts and does not abort.
