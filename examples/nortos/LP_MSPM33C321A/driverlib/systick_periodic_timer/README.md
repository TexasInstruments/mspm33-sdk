## Example Summary

This example demonstrates the use of the SysTick timer to generate periodic interrupts. The SysTick timer is configured to generate an interrupt every 500 ms. In the SysTick interrupt handler, the green LED is toggled, creating a blinking effect. The device remains in SLEEP mode while waiting for interrupts, showcasing low power consumption.

## Example Usage

The SysTick timer is configured with the following settings:
- Period: 16,000,000 cycles (500 ms at 32 MHz system clock)
- Interrupt: Enabled
- SysTick Timer: Enabled

The example also enables the SLEEP on exit feature of the CPU, which automatically puts the device into SLEEP mode when exiting an interrupt service routine. This demonstrates how to achieve low power consumption while still maintaining periodic functionality.

### Implementation Details

The SysTick configuration is handled in the `SYSCFG_DL_SYSTICK_init()` function, which is generated by SysConfig. The function uses `DL_SYSTICK_config()` to set up the SysTick timer with a period of 16,000,000 cycles.

In the main application:
1. The NVIC interrupt for SysTick is enabled using `NVIC_EnableIRQ(SysTick_IRQn)`
2. The device peripherals are initialized with `SYSCFG_DL_init()`
3. Sleep-on-exit mode is enabled with `DL_SYSCTL_enableSleepOnExit()`
4. The main loop enters an infinite wait-for-interrupt loop with `__WFI()`

The SysTick interrupt handler (`SysTick_Handler()`) toggles the green LED (PASS_LED) each time it's called, creating the blinking effect.

### Expected Behavior

Compile, load and run the example.

The green LED (PASS_LED) will toggle every 500 ms, creating a blinking pattern. The device will remain in SLEEP mode between interrupts, consuming minimal power.
